# Professional Astro Portfolio

A clean engineering portfolio built around a white / royal-blue / navy / cream visual system.

## Stack

- Astro 7
- React integration ready
- Tailwind CSS 4 ready
- Custom CSS design system
- Manrope typography

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Astro (usually `http://localhost:4321`).

## Personalize first

Edit `src/data/site.ts`:

- name + initials
- email
- GitHub
- LinkedIn
- resume path
- project links and copy
- skills

Put your resume at `public/resume.pdf`.

## Build

```bash
npm run build
npm run preview
```

## Design system

- White: `#FFFFFF`
- Primary blue: `#2F39A9`
- Navy: `#010736`
- Cream: `#FCF1D0`

The site intentionally uses restrained motion, editorial typography and content-led project cards instead of a generic developer-template aesthetic.
